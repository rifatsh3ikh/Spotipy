# Spotipy

Spotipy is a sleek and simple local music player built with Python. It provides a clean, modern user interface using the CustomTkinter library for its appearance and leverages Pygame for robust audio playback.

## Features

- **Local Audio Playback:** Play your favorite audio files directly from your computer, supporting formats like `.mp3`, `.wav`, `.ogg`, and `.flac`.
- **Modern UI:** A beautiful dark-mode interface built with CustomTkinter, featuring a green accent theme.
- **Playback Controls:** All the essential controls you need: Play/Pause, Next, and Previous song.
- **Playlist Management:** Add multiple songs to create a playlist. The playlist is displayed in a scrollable list, and you can play any song by clicking on it.
- **Volume Control:** Adjust the playback volume with a smooth slider and a real-time percentage display.
- **Automatic Playback:** Automatically plays the next song in the playlist once the current one finishes.

## Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/rifatsh3ikh/spotipy.git
    cd spotipy
    ```

2.  **Install the required dependencies:**
    This project requires `customtkinter` and `pygame`. You can install them using pip.
    ```bash
    pip install customtkinter pygame
    ```

## Usage

1.  Run the application from the project's root directory:
    ```bash
    python main.py
    ```

2.  Click the "➕ Add Songs" button to open a file dialog and select one or more audio files.

3.  The selected songs will appear in the playlist. Click on a song in the list to start playing it or use the main playback controls at the top.
